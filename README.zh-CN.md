# Seedmux 中继

[Seedmux](https://seedmux.com) 桌面端(和它的 `smx` 守护进程)与 iPhone 上的 Seedmux 不在同一个网络时,靠它接上。可以自己架一台,把机器指过去;也可以用官方的。

- **只转发,不看内容。** 手机和桌面配对时用 X25519 交换密钥,之后每条消息都端到端加密(XChaCha20-Poly1305)。中继只看得到最外层的信封:谁和谁在说话、说了多少,看不到终端、对话和屏幕。
- **内置 TURN。** 手机和桌面直连不上时(移动网络多是对称型 NAT),看屏幕的 WebRTC 画面经中继的 TURN 转发。凭据短期有效,只发给验证过身份的桌面。
- **推送通知**(只有官方中继):中继可以替桌面给 Seedmux iOS app 转发 APNs 推送。自己架的中继没有苹果的密钥,别加 `-apns-*` 参数。

部署、参数、端口见 [README.md](README.md) 和 [docs/self-hosting.md](docs/self-hosting.md)。

## 安全

- **桌面身份「先到先得」**:桌面第一次连上时带一把随机的中继密钥,中继按设备号记下它的哈希;之后再说自己是这台设备,必须拿出同一把。别人冒充不了、占不了它的推送和 TURN 额度。没有密钥的老版本桌面照样能连(不算验证过、没有 TURN),除非加 `-require-desktop-key`。
- **TURN 进不了内网**:只许转发到公网单播地址,本机、内网、链路本地(含云厂商元数据地址)、CGNAT、组播一律拒绝;每台桌面同时开的中转有上限。
- **防滥用**:连上后 15 秒内必须认证;每个 IP 最多 64 条连接;推送只许桌面发,每台每分钟 60 条、每条 4KB 以内;配对码不进日志。
